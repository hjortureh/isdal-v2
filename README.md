# ÍSDAL — Arkitektúr & Interior

Static marketing site for Ísdal architecture & interior design studio, in Icelandic.
Presents Ísdal as a company (founder Hildur Ísdal + Dagný + Sara).

## Structure

- `index.html` — forsíða (hero, verkefni Ísdal, þjónusta, stofan, fréttir, CTA)
- `verkefni.html` — project index with filters (Arkitektúr / Innanhússhönnun / Fyrri verkefni)
- `verkefni/*.html` — 9 project detail pages; front-page projects are Ísdal's own,
  "fyrri verkefni" are attributed to the firm they were done at (Arkitema, Cedervall, …)
- `um-okkur.html` — about: approach + clickable team grid
- `folk/*.html` — team member pages (Hildur incl. CV)
- `frettir.html` — news, incl. links to mbl.is coverage of both kitchen projects
- `hafa-samband.html` — contact (Austurstræti 12a) + form (posts via `mailto:` — no backend yet)
- `css/style.css` — the whole design system
- `js/main.js` — menu, scroll reveal, project filter, contact form
- `assets/img/` — images from the previous isdal.is, mbl.is coverage, and districthive.com
  (low-res; presented at modest sizes by design)

## Editing

All pages are generated by `build.py` (shared header/footer, project + team data live there).
Edit copy/projects in `build.py`, then:

```bash
python3 build.py
```

CSS and JS are plain files, edited directly.

## Preview

```bash
python3 -m http.server 8737
```
