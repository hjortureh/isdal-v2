# ÍSDAL — Arkitektúr & Interior

Static marketing site for Ísdal architecture & interior design studio, in Icelandic.
Presents Ísdal as a company (team of three, founded by Hildur Ísdal).

## Structure

- `index.html` — forsíða (hero, valin verkefni, þjónusta, stofan, fréttir, CTA)
- `verkefni.html` — project index with category filters
- `verkefni/*.html` — 9 project detail pages
- `um-okkur.html` — about: approach, team (Hildur, Dagný, Sara), founder bio + CV
- `frettir.html` — news
- `hafa-samband.html` — contact info + form (posts via `mailto:` — no backend yet)
- `css/style.css` — the whole design system
- `js/main.js` — menu, scroll reveal, project filter, contact form
- `assets/img/` — WebP images pulled from the previous isdal.is (low-res; presented at modest sizes by design)

## Editing

All pages are generated by `build.py` (shared header/footer + project data live there).
Edit copy/projects in `build.py`, then:

```bash
python3 build.py
```

CSS and JS are plain files, edited directly.

## Preview
